# v7.4.0 Audit-Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Resolve the 2026-07-14 answer-quality audit backlog (GitHub issues #130–#155, #158, plus pragmatic slices of #153/#156/#159) on the `v7.4` release branch so v7.4.0 ships with the fixes.

**Architecture:** Fixes are grouped into tracks that own disjoint files so they can be implemented by parallel subagents and merged without conflicts; shared-file tracks (samples.js, builders.js, register-index-tools.js) run sequentially afterward. New deterministic contract tests (#155) are written first as a red harness and wired into `npm test` last, once all tracks are green.

**Tech Stack:** Node.js ESM, `node:test`, zod, MCP SDK ^1.25.2. No TypeScript. No new dependencies.

## Global Constraints

- Branch: work lands on `v7.4` (release PR #129). Base = `origin/v7.4`.
- Tests in a worktree need `MCP_DATA_DIR=/home/louie/simple-dynamsoft-mcp/data` (worktree submodules are empty).
- Run `npm run test:unit` (fast) after every task; `MCP_DATA_DIR=... npm test` before every push.
- The `test:package` suite fails in worktrees for environmental reasons (hardcoded repo-local data path) — pre-existing, not a gate.
- Conventional commits; every commit that resolves an issue includes `Fixes #NNN` lines.
- Style: match surrounding code; ESM imports with `.js` extensions; no new runtime deps.
- Data under `data/` is read-only in this effort (git submodules); all fixes are server-side. Enrichment derived from data happens at index-build time in code, not by editing data.
- Deferred (explicitly OUT of v7.4.0): #157 (eval harness — needs external query mining), #159 content authoring (upstream sample/doc work; only the RN capability statement lands, in Task 3), #153 URI-scheme overhaul (only TOC mode + miss-recovery land), #156 full telemetry pipeline (only structured per-call logging + zero-result capture land).
